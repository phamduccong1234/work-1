# Git

- Học về các câu lệnh git remote, git push, git pull, git stashing, git clone

* git clone: Lấy code từ 1 repo có sẵn về máy local
* git push: Đưa code từ vùng repository ở local của 1 nhánh lên remote
* git pull: Lấy code từ 1 nhánh về nhánh local
* git stash save: Lưu trữ các thay đổi hiện tại ở vùng staging vào 1 vùng nhớ tạm
* git stash pop: Lấy lại công việc đang thay đổi
* Quy trình tạo PR và review code
* Convention trong Git : feat/ , fix/ , conf/ , chore/
